# LangChain-and-Runnables

A hands-on repository for learning and experimenting with **LangChain, Runnables, Tool Calling, Agents, and LLM-based workflows**.

This repository contains small, focused examples that demonstrate how different LangChain concepts work in practice.

##  Topics Covered

- LangChain Runnables
- RunnableSequence
- RunnablePassthrough
- Parallel Runnables
- Tool Calling
- Custom Tools
- Agents
- LLM Integration
- Environment Variables
- Building AI-powered workflows

##  Tech Stack

- Python
- LangChain
- LangGraph
- Groq
- OpenAI-compatible LLMs
- python-dotenv
